# Body Journey
Educational Android game for kids about the human body (26 levels). Engine: Godot 4.3, GDScript.
Original characters only; no assets from "Once Upon a Time... Life". See `docs/STATUS.md` for what is done and what is unverified (code was NOT run in Godot and no APK was built when this was generated).
